# Scheme Interpreter
Scheme interpreter in python
# Functionality

Support for load, define (including recursion), if and lambda expressions

**Implemented Functions:**
- '+'
- '-'
- '/'
- '*'
- and
- or
- length
- not
- min
- max
- if
- else
- sqrt
- reverse
- pow
- even?
- odd?
- quotient
- remainder
- negative?
- positive?
- list?
- zero?
- equal?
- null?
- apply
- eval
- cdr
- car
- cadr
- cons
- append
- map
- list
- display
- '='
- '<'
- '>'
- '<='
- '>='
## Usage
to invoke interpreter write
>python main.py

to run the tests write 
>(load TESTS.scm)

while running the interpreter
